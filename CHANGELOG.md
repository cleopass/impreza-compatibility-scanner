# Changelog

## 0.9.0-beta — 2026-11-20

First public beta.

* Read-only scan of posts (all post types and statuses except trash), Reusable Blocks, Page Templates, `vc_grid_item`, post meta, widgets and WPBakery "My templates".
* Classification: Compatible / Incompatible / Unknown / Unregistered, with the evidence behind each decision.
* Front-end shortcode registry capture (WPBakery registers most shortcodes only on the front end).
* Verified data: Impreza / US Core 9.6.1, WPBakery 9.2, Ultimate Addons for WPBakery 3.21.6.
* Batched scanning with progress, cancel and resume; content and shortcode views; CSV export.
